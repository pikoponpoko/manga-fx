# Object Library（オブジェクト保存）— After Effects スクリプト

よく使うレイヤー・コンポ・エフェクト・エクスプレッション・イーズを保存して、別のプロジェクトでも 1 クリックで呼び出すパネルです。

## 入れ方

`ObjectLibrary.jsx` を After Effects の `Scripts/ScriptUI Panels` フォルダに入れ、再起動後に **ウィンドウ > ObjectLibrary.jsx** で開きます。ファイルへの書き込みを使うので、**環境設定 > スクリプトとエクスプレッション > スクリプトによるファイルへの書き込みとネットワークへのアクセスを許可** をオンにしてください。

## 使い方

上のメニューで種類を選び、**Save** で保存、一覧で選んで **Apply**（またはダブルクリック）で呼び出します。

| 種類 | Save で保存するもの | Apply でしたこと |
|---|---|---|
| Layers | 選んだレイヤー（エフェクト・マスク・キーフレーム・エクスプレッション・親子関係・トラックマットを含む） | 開いているコンポの現在の時間に置く |
| Comps | プロジェクトパネルで選んだコンポ（なければ開いているコンポ）。中のプリコンポも含む | プロジェクトの「Object Library」フォルダにコンポを作って開く |
| Effects | 選んだレイヤーの、選んだエフェクト（選んでいなければ全部） | 選んだレイヤーすべてに足す |
| Expressions | 選んだプロパティのエクスプレッション | 選んだプロパティすべてに入れる |
| Ease | 選んだキーフレームの補間と速度・影響 | 選んだキーフレームすべてに当てる |

Layers / Comps / Effects は保存時の画面をサムネイルにします。Rename・Delete で整理、**Folder...** で保存先を変え（チームの共有フォルダなど）、**Show** で保存先を開きます。

## 保存の中身

- 保存先の既定: ユーザーフォルダの `MangaFX/ObjectLibrary/<種類>/`（Windows は `%APPDATA%`、Mac は `~/Library/Application Support`）
- 1 件 = `名前.kzobj`（テキスト）＋ `名前.png`（サムネイル）。フォルダごとコピーすれば別の PC でも使える
- フッテージは素材ファイルの場所を覚えておき、呼び出し先のプロジェクトになければ読み込みます。ファイルが見つからなければプレースホルダーになります

## 制限

- 値を持たない特殊なプロパティ（カーブなどのグラフ）、レイヤースタイル、エッセンシャルプロパティは保存しません
- エクスプレッションが別のレイヤー名やコンポ名を参照していると、呼び出し先で名前が違えばエラーになります（呼び出し後に警告を表示します）

## 動作環境

After Effects 2020（17.0）以降を想定。サムネイルは After Effects の非公開機能（saveFrameToPng）を使うため、版によっては作られません。
